React Internals

How React actually works under the hood…kinda deep.

How React works under the hood, meaning reconciliation, the Fiber architecture, the work loop, the commit phase, scheduling and hooks, at the level a frontend developer needs to reason about their own code. It's not a workshop write-up. The notes are built from react.dev, the React team's own architecture writing, and the React 19.2.5 source (react-dom-client.development.js, scheduler.development.js), which every algorithm here was checked against.

Everything follows one throughline. Your components return elements → React reconciles them against a tree of fibers → it walks that tree in a loop it can pause → it commits the result to the DOM in one go. The optimizations in React Performance and the concurrent features in React Suspense are all consequences of that pipeline.
